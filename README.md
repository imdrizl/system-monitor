# System Monitor
A lightweight real-time system monitoring tool built with python.

## Features
- CPU Usage
- Memory Usage
- Disk Usage
- System Information
- System Uptime

# Requirements
- Python 3.8 or newer
- Windows or Linux
No additional packages required

# Installation
Clone the Repository:
```git clone https://github.com/imdrizl/System-Monitor.git```

Navigate into the project folder:
```cd System-Monitor```

Run the program:
```python system_monitor.py```

# Usage
The dashboard automatically updates every second.

Press Ctrl + C to terminate the program.
